# 角色权限说明

## 适用范围

本平台是制造设备售后报修的分诊辅助工具。角色权限用于限制数据和流程操作，不得修改规则分诊、安全限制或现场维修结论。

## 角色划分

| 角色 | 可执行操作 | 不可执行操作 |
| --- | --- | --- |
| 客服专员 AGENT | 查看工单、提交报修、补问、录入客户补充、转人工、手动请求客服参考 | 确认、修订、关闭、删除工单；管理账户 |
| 复核主管 REVIEWER | 查看工单、补问、录入补充、转人工、确认、修订、关闭、手动请求客服参考 | 删除工单；管理账户 |
| 平台管理员 ADMIN | 上述全部业务操作；删除工单；后续账户管理能力 | 不能绕过安全风险、停机、未知状态、信息不完整和规则冲突时的人工确认要求 |

## 强制业务边界

角色权限只控制“谁可以发起操作”。安全风险、停机、运行或安全状态未知、信息不完整、规则与模型冲突的工单，仍由现有规则保守转人工。复核主管和管理员也不能通过角色权限让系统给出自动现场维修结论。

## 首次初始化

在本机 `.env` 中填写 `BOOTSTRAP_ADMIN_USERNAME` 与 `BOOTSTRAP_ADMIN_PASSWORD`，保持 `AUTH_ENABLED=true`，然后运行：

```powershell
.venv\Scripts\python.exe 运行脚本\init_db.py
```

该脚本只在账户表为空时创建首个管理员，并且只保存密码哈希。账号创建后访问平台会进入登录页。真实密码、数据库文件和 `.env` 不得提交到 Git。

## 当前限制

当前版本已提供登录、会话、服务端权限校验、可信操作人留痕，以及管理员网页创建账号、修改角色、启停账号和重置密码。尚未提供多人并发会话治理、密码重置后的全端会话失效、企业单点登录或网关级访问控制；这些能力应在面向真实企业部署前补齐。
