# 系统运行截图说明

本目录截图于 2026 年 11 月 25 日，在本地启动 Flask 服务后，用浏览器自动登录（管理员账号）逐页截取，均为系统真实运行画面。

## 截图清单

| 文件名 | 页面 | 展示内容 |
| --- | --- | --- |
| 01_登录页.png | 登录页 | 系统的账号登录入口，启用登录鉴权与 CSRF 防护 |
| 02_工单列表.png | 工单列表 | 三条报修工单，含设备型号、故障摘要、状态、提交时间，以及"查看详情"和红色"删除"按钮 |
| 03_报修提交表单.png | 提交报修 | 报修填写页：设备类型、型号、故障描述、报警码、安全风险、停机状态等字段 |
| 04_工单详情_分诊结果.png | 工单详情（完整页） | 一条工单从报修信息到分诊建议、知识参考、客服操作区的完整画面 |
| 05_管理员账户管理.png | 账户管理 | 管理员创建账号、调整角色、启停账号、重置密码 |
| 06_知识库管理.png | 知识库管理 | 新增知识条目表单，以及 20 条公开维修资料的列表与来源 |
| 07_分诊建议_特写.png | 工单详情（局部特写） | 分诊建议区块：故障类别、建议优先级、判断依据、建议补充信息、建议售后处理、处理原因 |
| 08_维修知识参考_特写.png | 工单详情（局部特写） | 维修知识参考区块：匹配到的资料条目、处置方向与来源 |
| 09_工单详情_首屏.png | 工单详情（首屏） | 详情页首屏：报修基本信息与分诊结果摘要 |

## 说明

- 完整页截图（04、06）采用整页捕获，内容全面但字号较小；特写截图（07、08）截取关键区块，便于看清分诊结果细节。
- 截图数据均为虚构演示内容，不含真实客户信息。
- 工单的分诊结果来自系统自动计算（规则分诊 + 知识分层匹配），在提交报修时生成；客服操作区为人工处理入口。
