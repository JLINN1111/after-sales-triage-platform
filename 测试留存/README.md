# 测试留存

本目录用于沉淀可复现的测试案例与实际结果，供阶段验收和后续报告使用。

## 留存规则

每次进行自动检验、接口检验或浏览器端人工验证时，均应新建或补充对应阶段目录，并至少保留：

1. 测试日期、测试人和测试类型；
2. 测试输入、预期结果、实际结果与通过状态；
3. 可复现的测试命令或页面操作；
4. 发现的问题、复现步骤和处理结论（如有）。

不得保存真实客户个人信息、未经授权的内部工单、密钥或生产现场敏感资料。页面测试应使用虚构或已批准的演示数据。
