# 阶段二浏览器端测试记录：精确知识匹配

## 基本信息

| 项目 | 内容 |
|---|---|
| 测试编号 | E2E-S2-EXACT-001 |
| 测试日期 | 2026-11-20 |
| 测试方式 | 浏览器端人工验证 |
| 测试数据性质 | 虚构基准设备与公开原厂资料 |
| 状态 | 通过 |

## 测试目标

验证提交报修后，平台能够保存工单、在详情页中文展示分诊结果，并在设备台账、设备信息和报警代码均被确认时返回精确知识匹配。该结果仅提供原厂资料的处置方向，不替代现场维修诊断。

## 输入

| 字段 | 值 |
|---|---|
| 设备类型 | 数控机床/加工设备（`CNC`） |
| 设备型号 | `VF-2` |
| 设备编号 | `BASELINE-VF2-001` |
| 故障现象描述 | 控制柜温度过高，风扇异常 |
| 发生时运行状态 | 运行中 |
| 是否停机 | 否 |
| 是否存在安全风险 | 否 |
| 报警代码状态 | 有报警代码 |
| 报警代码 | `253` |

## 预期结果

1. 工单可成功提交并出现在工单列表中；
2. 故障类别显示为“温度或冷却异常”，建议优先级为“普通”；
3. 不建议转人工；
4. 知识匹配等级显示为“已匹配对应设备知识”；
5. 展示 `KB-HAAS-VF2-001`，且页面使用中文展示词；
6. 资料处置方向保留安全提示，不应被表述为确定现场诊断或替代现场维修操作。

## 实际结果

工单 `T20261120-0001` 成功创建并出现在列表中。详情页显示“温度或冷却异常”“普通”“建议转人工：否”，并显示“已匹配对应设备知识”及 `KB-HAAS-VF2-001`。页面展示为中文；知识条目处置方向包含“停止继续加工并转人工检查”“不得绕过过热保护”等安全限制。结果符合预期。
