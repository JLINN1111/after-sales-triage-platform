# 版本化训练候选快照记录

日期：2026年11月22日

核查发现，候选审核记录原先没有数据来源分级或案例家族字段，本地数据库也没有已接受候选。因此系统不能自行断言候选为课程虚构数据，也不能以工单编号猜测案例家族。

现已将“接受”限制为管理员明确确认 `COURSE_SYNTHETIC` 并填写案例家族标识的样本。构建脚本仅从这些已接受样本显式生成被 Git 忽略的本地快照，保留候选来源、审核后类别、案例家族和逐样本 SHA-256；未确认范围、案例家族格式无效或同一家族类别冲突的样本进入排除清单。

快照状态固定为“仅快照，未训练”，不会训练或评测模型，也不读取冻结最终测试集。真实工单仍须走受控脱敏、双人标注和独立测试流程，不能经此入口进入训练数据。

验收结果：版本化快照与候选审核联合测试 35 项通过；全量回归测试 83 项通过。
