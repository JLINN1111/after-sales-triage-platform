# 对话式报修信息采集助手接入记录

日期：2026-11-25

## 功能范围

- 在提交报修页提供“对话式补充信息”，通过自然语言追问帮助用户补充设备状态、报警代码和可观察现象。
- 在工单处于“待补充信息”时，报修业务人员可继续对话，并把经本人采用的字段建议填入既有补充表单。
- 助手不输出故障类别、处理优先级、知识匹配结论或维修方案；现有规则分诊和知识匹配仅在正式提交或保存补充信息时运行。
- 用户可以采用或忽略每条字段建议。采用记录与对话消息独立保存，作为后续经审核的模型再训练候选资料，不自动进入训练。

## 外部模型与安全边界

- 支持 DeepSeek 与阿里云百炼（DashScope / Model Studio）兼容接口，模型服务默认关闭。
- 只有本机 `.env` 同时设置 `LLM_ENABLED=true` 和 `LLM_ALLOW_EXTERNAL_CALLS=true` 后才会调用外部服务。
- 对外只发送必要的脱敏文字；不发送账户、设备编号、附件原文件或地址。
- 模型必须返回固定 JSON；服务端仅接受允许的表单字段。调用失败、超时或输出不合格时提示手工填写，不影响工单主流程。
