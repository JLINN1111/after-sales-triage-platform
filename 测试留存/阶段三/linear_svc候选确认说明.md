# LinearSVC 候选确认说明

在正式训练集内按 `case_id` 分组进行五折比较后，字符级 TF-IDF 加 LinearSVC 为最高的传统候选。随后仅在当前固定的案例家族隔离验证集上确认一次。

| 指标 | 结果 |
| --- | ---: |
| 验证样本数 | 60 |
| Accuracy | 0.817 |
| Macro F1 | 0.822 |
| 电气控制 F1 | 0.923 |
| 机械传动 F1 | 0.778 |
| 传感通信 F1 | 0.786 |
| 温度冷却 F1 | 0.800 |

该确认只适用于课程虚构、人工审核、案例家族隔离的当前开发集。LinearSVC 尚未接入分诊服务：置信度校准、人工复核阈值和安全闸门回归尚未完成；安全风险、停机、信息不完整、运行或安全状态未知、规则与模型冲突的工单仍必须转人工。冻结最终测试集未读取。
