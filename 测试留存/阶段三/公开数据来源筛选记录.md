## 适配性审查

1. Zenodo 的 Annotated Maintenance Logbook 有 CC BY 4.0 许可，内容为英文航空发动机维修短文本。它可为维修记录字段和人工审核提供参考，但与中文制造设备售后报修的设备、语言、标签及业务后果均不一致，因此不得直接合并入当前三分类训练集。
2. UCI AI4I 2020 具 CC BY 4.0 许可，但属于合成数值预测维护数据，不能验证或提高当前文本分类器的真实业务指标。
3. NASA IMS Bearings 与 PHM Society Gearbox 数据是状态监测或振动信号数据，不能代替报修文本和人工服务结论。
4. 本轮新增中文来源筛选：公开 GitHub 化工报修文本项目的字段最接近平台，但其上游 Kaggle 许可、数据生成过程和权利链尚未完成核验，因此禁止下载或训练；国家基础学科公共科学数据中心的工业机器人资料需要登录并同意协议，且公开信息未证明其含报修文本；“智能制造业故障诊断推理数据集”需联系购买，不能视为开放数据。

## 验收边界

- 本轮为资料筛选与使用边界登记，不运行新的训练、验证或冻结测试。
- 既有冻结最终测试不得重新执行；既有本地回归结果为 48 项通过。
- 外部数据后续若获准下载，须先进行许可核验、文件校验、单独分层、字段适配审查及人工复核；完成这些步骤前不得用于模型指标宣传或真实业务自动分诊。

## 免费注册来源的决策

建议优先注册国家基础学科公共科学数据中心，并仅申请与当前设备范围相关的工业机器人故障检测、工业机器人滚动轴承或旋转部件故障诊断资料。它们的机构来源与申请流程可核验，但数据形态主要为信号、特征或图像，不能作为当前中文报修文本分类器的训练、验证和验收样本。

本轮不建议注册或下载上游许可未核验的 GitHub 化工报修文本项目，也不建议采购商业数据集。用户完成平台注册并确认具体数据集的使用协议后，下一步应是下载到独立参考区，执行许可留存、文件校验、字段审查和人工审核；通过前不接入训练或生产推理。

## 与真实业务输入的复核结论

平台后续处理的是中文真实业务报修文本。已复核工业机器人滚动轴承数据集：其虽为 CC0、11MB CSV、机构来源明确，但内容为电流和振动信号及健康状态，不含真实报修文本、人工结论或维修处置字段。因此撤销该数据集的下载候选资格，不下载、不接入知识参考区，也不计入样本扩充。

公开资源中，MaintIE/MaintNorm 的英文维修工单短文本与 AssetOpsBench 的工单与故障代码更适合验证字段抽取、缩写规范化、检索和人工确认流程；它们均不得用于宣称中文真实业务分类性能。当前唯一能提高该模型可信度的主数据源，仍是取得授权、脱敏、双人标注和影子运行评估后的本企业历史工单。
