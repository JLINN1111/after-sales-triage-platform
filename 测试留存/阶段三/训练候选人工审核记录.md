# 训练候选人工审核记录

日期：2026年11月22日

管理员可对已批准、处理结果为已解决、类别与故障描述完整的反馈逐条作出“接受为正式训练集候选”或“拒收”决定，并可在接受时修订类别。同一已批准反馈只能形成一条候选审核记录；已审核结论在页面中保留展示，不会被后续提交覆盖。

审核页面只展示经基础脱敏后的故障描述：手机号和邮箱以类型占位符替换；含身份证号码的反馈不会进入候选审核。服务端在提交时再次校验反馈批准状态、已解决状态、字段完整性、候选类别和管理员权限，不能仅依赖页面隐藏控制。

接受结论仅表示可进入后续版本化正式训练集构建，仍须保留来源、审核结论、样本哈希、排除清单和案例家族隔离；本次功能不会自动训练、更新当前模型或重复运行冻结最终测试集。

验收结果：候选审核专项测试 33 项通过；全量回归测试 81 项通过。
