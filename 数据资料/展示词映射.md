# 展示词映射

## 使用约定

- 数据库、规则脚本、接口传输保留英文代码，不自行改名。
- 用户、客服和工单详情页展示下表中的中文名称，不直接展示英文代码。
- 中文名称仅用于显示，不能作为程序判断条件。

## 故障类别

| 内部代码 | 中文展示 |
|---|---|
| `ELECTRICAL_CONTROL` | 电气或控制异常 |
| `MECHANICAL` | 机械或传动异常 |
| `THERMAL_COOLING` | 温度或冷却异常 |
| `SENSOR_COMMUNICATION` | 传感或通信异常 |
| `OTHER_UNKNOWN` | 其他或暂无法判断 |

## 优先级

| 内部代码 | 中文展示 |
|---|---|
| `NORMAL` | 普通 |
| `HIGH` | 优先处理 |
| `URGENT` | 紧急处理 |

## 知识匹配等级

| 内部代码 | 中文展示 | 页面提示 |
|---|---|---|
| `EXACT` | 已匹配对应设备知识 | 已找到与当前设备信息相符的参考资料。 |
| `REFERENCE` | 找到参考信息，需人工核对 | 找到同类设备参考资料，请人工核对型号和控制系统。 |
| `NONE` | 暂未找到适用知识 | 暂未找到对应资料，请补充设备信息或转人工处理。 |

## 常见人工确认原因

| 内部依据或原因 | 中文展示 |
|---|---|
| `RULE-SAFETY-YES` / 存在安全风险 | 存在安全风险，需人工处理。 |
| `RULE-SHUTDOWN-YES` / 设备已停机 | 设备已停机，需优先处理。 |
| `RULE-SAFETY-UNKNOWN` / 安全风险尚未确认 | 请先确认现场是否存在安全风险。 |
| `RULE-SHUTDOWN-UNKNOWN` / 停机状态尚未确认 | 请确认设备目前是否停机。 |
| `RULE-CATEGORY-NO-DIRECT-EVIDENCE` / 故障类别信息不足 | 现象信息不足，暂无法判断故障类别。 |
| `RULE-CATEGORY-CONFLICT` / 故障类别线索冲突 | 现象可能涉及多个方向，需人工核对。 |
| `RULE-KNOWLEDGE-REFERENCE` / 仅命中参考知识 | 仅找到参考资料，不能作为确定结论。 |
| `RULE-KNOWLEDGE-NONE` / 未找到适用知识 | 未找到适用知识，建议补充设备信息。 |
