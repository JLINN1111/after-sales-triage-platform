# 公开参考数据层

本目录用于保存经许可核验的公开维护数据的来源登记、字段检查和使用边界。它与 `训练数据`、`维修知识` 和真实业务导入目录隔离。

原始下载文件位于 `原始数据/`，已被 Git 忽略；仓库只保留可复现下载脚本、来源登记与处理记录。

## 强制边界

1. 外部数据不得直接并入当前 216 条课程样本训练集、验证集或冻结最终测试集。
2. 不得用外部数据重新报告当前 TF-IDF + LinearSVC 的 Accuracy、Macro F1 或任何真实业务指标。
3. 只有在许可、来源、字段和人工映射均完成审核后，才能作为单独的外部参考评测集或知识建设素材。
4. 公开数据不能替代本单位脱敏工单和人工最终维修结论。
