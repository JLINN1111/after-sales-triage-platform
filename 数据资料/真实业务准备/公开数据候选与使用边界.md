# 公开数据候选与使用边界

更新时间：2026年11月21日

本清单仅用于补充资料调研、字段设计和影子评估准备。任何公开数据在进入项目之前，仍须记录下载时间、版本、校验值、许可文本和处理过程，并通过脱敏校验、双人标注及人工审核。不得把下列数据直接当作本平台真实制造设备售后工单，也不得据此放宽人工确认规则。

中文公开数据的稀缺并不意味着可放宽审查。对于当前平台，优先级应是：经过业务授权且脱敏的本企业历史工单，其次是许可和来源均可核验、字段能映射的中文公开文本；传感器数据、仿真数据和跨行业文本只能作为独立参考，不能替代真实业务验证。

## 免费注册来源的使用决策

推荐注册：国家基础学科公共科学数据中心。该平台提供由研究机构提交的工业机器人、轴承、旋转部件等故障诊断资料，需注册并同意数据使用协议。下载前应逐个保存数据说明、数据许可、引用方式、版本和申请记录。

推荐用途：将完成许可审查的资料放入独立的 `PUBLIC_REFERENCE_ONLY` 区域，提炼设备对象、部件、故障模式和告警字段，供知识库候选条目和人工审核词表使用。它们不得改写高风险、停机、信息不完整或规则模型冲突时的人工确认机制。

不推荐用途：这些资料主要为电流、振动、时频图像或时序故障标签，并不是中文报修文本。因此不应直接并入当前 TF-IDF 加线性分类器的训练、验证或冻结最终测试；这样做只会造成“传感器信号任务”与“自然语言报修分诊任务”的表面样本量增加，不能提高真实业务可信度。

不推荐注册或下载：上游许可尚未核验的 GitHub 化工报修文本项目；以及需要购买或另签商业授权的数据集。

## 与真实报修输入的适配优先级

当前平台的后续输入是中文真实业务报修，目标是对故障现象进行保守初筛，而不是对传感器波形或图像做诊断。因此以下优先级替代“下载工业故障数据即可扩样”的做法：

1. **业务授权的脱敏历史工单：唯一可用于提升当前分类器的主数据源。** 每条记录至少需要保留脱敏后的报修描述、设备类型或系列、故障大类、人工最终结论、人工确认标记和案例族标识；安全风险、停机、信息不完整与冲突工单必须保留为人工确认样本。
2. **中文维修工单知识库：仅在权利人书面授权后作为辅助数据。** 已发现“厂区设备维修知识库数据集”目录说明其包含设备名称、故障描述、维修内容、备件和费用等字段，结构最接近平台，但页面仅证明其为企业内部工单资产，尚未证明可公开下载或可用于训练，不能擅自采集。
3. **MaintIE 与 MaintNorm：可用于工程方法验证，不用于中文类别训练。** 两者为 MIT 许可的英文维修工单文本资源，可用于完善脱敏、缩写规范化、实体抽取和“对象—状态—动作”字段设计；不得把英文指标或翻译后文本当作中文真实业务指标。
4. **AssetOpsBench：可用于智能体流程与只读工单查询测试，不用于当前分类器训练。** 该 IBM 资源包含工单、故障代码与工业资产操作场景，适合验证“检索—规则—人工确认”编排；与中文现场报修语料不同。
5. **工业机器人轴承信号集：排除。** 虽是 CC0 的官方免费数据，但字段为电流和振动信号，与自然语言报修分诊任务不匹配，不下载、不接入、不计入样本量。

## 使用门槛

1. 只从来源主页或其明确指向的官方下载地址获取；不使用来源不明的二次打包数据。
2. 逐项保存许可、引用信息、版本、下载日期与文件校验值；许可不清或限制与预期用途冲突时，不导入。
3. 公开数据必须单独分层保存，并标明 `PUBLIC_REFERENCE_ONLY`；不得与授权业务工单混为同一训练集，也不得进入最终验收集。
4. 语言、设备类型或任务目标不一致时，只能用于字段设计、术语参考或独立探索，不能用来声称模型在真实业务中有效。
5. 真实业务样本仍以完成脱敏、数据授权、案例族隔离、双人独立标注和影子运行评估为准；安全风险、停机、信息不完整及规则与模型冲突工单一律人工确认。
