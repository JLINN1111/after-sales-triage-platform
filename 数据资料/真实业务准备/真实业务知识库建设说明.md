# 真实业务知识库建设说明

## 目标

知识库只纳入与本单位实际设备范围相符、来源可追溯、经业务负责人确认的维修资料。它用于检索和分诊辅助，不替代现场诊断、设备原厂手册或安全程序。

## 成员1工作流程

1. 在 `设备台账.csv` 登记实际设备的类型、品牌、型号、控制系统和软件版本；`asset_token` 使用内部脱敏标识，不写客户名称、联系人或精确地点。
2. 在 `知识资料登记.csv` 登记每份已获授权的手册、报警码表、SOP 或历史处置记录，并填写资料版本、章节、存放位置和授权状态。
3. 仅将同时满足以下条件的资料转成知识条目：适用机型明确、来源定位明确，且由你确认可用于真实业务。
4. 知识库内的条目默认就是可供平台参考的正式内容；未纳入知识库的资料不得自动匹配。
5. 真实工单先在受控环境中脱敏，使用 `脱敏工单导入模板.csv` 导入；原始工单与脱敏副本分开保存，且不相互覆盖。

## 最小准入标准

| 对象 | 准入要求 |
|---|---|
| 真实设备 | 型号、控制系统和版本可确认，且已登记资产脱敏标识 |
| 知识资料 | 来源、版本、适用范围和章节定位齐全 |
| 知识条目 | 可回溯到登记资料，且由你确认可用于真实业务 |
| 真实工单副本 | 已去除联系人、电话、地址、客户名等非必要信息，并完成复核 |
