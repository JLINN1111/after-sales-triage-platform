# 第二部分　阶段二任务下发：分诊规则算法接入（请你完成）

## 你需要完成的功能

1. 实现 `app/algorithms/rules.py`：从工单字段提取现象标签，判定粗粒度故障类别，输出 `predicted_category`、`priority`、`evidence_codes`、`reason` 等建议字段。
2. 实现 `app/algorithms/missing_info.py`：识别缺失字段并生成补问，输出 `missing_fields`、`follow_up_questions`；信息不足或类别冲突时转人工。
3. 严格执行安全优先规则：`safety_risk=YES` 或 `shutdown=YES` 为 `URGENT` 并转人工；`safety_risk=UNKNOWN` 或 `shutdown=UNKNOWN` 为 `HIGH` 并转人工；只有安全状态明确为 `NO`、未停机且无其他升级条件时才可为 `NORMAL`。
4. 固定输出 `model_version=rules-v0.1`；规则命中时 `category_confidence` 保持为空，不得伪造概率。
5. 遵循规则顺序：先算缺失字段并检查安全/停机状态，再提取现象判类别，最后进行知识检索。
6. 提供可调用的分诊服务入口，供工单提交后写入工单；`category_confidence` 等字段按规则文档保持不变。
7. 安全风险、已停机、信息不足或类别冲突时，只输出检查方向与人工确认建议，不输出确定维修结论。
